## Recommended direction

Polish the existing platform around one person record, one recruitment pipeline and one rota. Lead the website with healthcare, offering both direct care and staffing, alongside cleaning contracts, security staffing and training. Training administration records attendance and evidence; it does not deliver an LMS.

Use the company green, #33512d, across a calm office application, a simple mobile staff portal and a more personal public website. Keep shared information editable in the CMS without turning the whole website into a page builder.
